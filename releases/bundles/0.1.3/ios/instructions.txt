BAREGPS ROUTE MAKER - IOS
Version 0.1.3 build 7

This is an Xcode source bundle, not an installable IPA or TestFlight download. Run npm ci, then npm run native:sync. Open ios/App/App.xcodeproj in Xcode, choose your development team and connected iPhone, and build/run. The bundled web assets are ready. The iOS dependency path is local to this project.

Native target: iPhone only. iPads and other tablets should use https://appsbyonzy.dev/tools/baregps-route-maker/ . Apple may still offer iPhone compatibility mode on iPad.

Maps and terrain require internet. Route lines do not automatically follow paths.
